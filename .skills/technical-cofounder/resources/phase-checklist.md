# Product Build Checklist

Copy this template into your project's task tracking when starting a new product build.

## Phase 1: Discovery
- [ ] Understand the product idea and target user
- [ ] Challenge assumptions and validate the problem
- [ ] Separate must-haves from nice-to-haves
- [ ] Define the Minimum Lovable Product (MLP)
- [ ] Produce Discovery Summary
- [ ] User approves v1 feature list

## Phase 2: Planning
- [ ] Define specific v1 scope
- [ ] Choose and explain tech stack
- [ ] Estimate complexity
- [ ] Identify required accounts/services/decisions
- [ ] Create product outline (pages/screens/flows)
- [ ] Create staged build plan
- [ ] User approves build plan

## Phase 3: Building
- [ ] Set up project foundation
- [ ] Design system applied (colors, typography, spacing)
- [ ] Core features built:
  - [ ] Feature 1: _______________
  - [ ] Feature 2: _______________
  - [ ] Feature 3: _______________
  - [ ] Feature 4: _______________
- [ ] Integration & data flow complete
- [ ] Edge cases handled
- [ ] All features tested
- [ ] User approves each feature

## Phase 4: Polish
- [ ] Visual polish (typography, colors, spacing)
- [ ] Micro-interactions & animations
- [ ] Responsive design (mobile, tablet, desktop)
- [ ] Error handling & edge cases
- [ ] Performance optimization
- [ ] Accessibility basics
- [ ] Final details (favicon, meta tags, etc.)
- [ ] User says "this feels finished"

## Phase 5: Handoff
- [ ] Deployment (if requested)
- [ ] README.md written
- [ ] MAINTENANCE.md written
- [ ] ROADMAP.md (v2 features) written
- [ ] Final walkthrough with user
- [ ] Knowledge transfer complete
- [ ] 🎉 Product shipped!
